# README screenshots

Captured from SeismicGuard **v0.9.0** on macOS (1480×900 main window,
1200×800 Workbench, dark theme; one light-theme Data capture).

The UI is localized and theme-aware; the English locale is used for the
screenshots. Screens are from a real session (USGS/IRIS/ShakeNet data), not
mockups. Re-capture with `python -m shakevision` if a future release changes
the layout significantly.
